KITES RVSS CHOLESKY SCALING BENCHMARK
=====================================

Purpose
-------
Measure scalar versus vector Cholesky kernels as matrix dimension
increases. Every input runs on the RVSS processor. Results are
simulator counters, not wall-clock timings.

Methodology
-----------
Dimensions: 2, 3, 4, 5, 6, 8.
Samples per dimension: 1
Input cases: 6 independently seeded inputs. Inputs are deterministic.
Seed formula: 20261108 + N*10000 + sample; sample is zero-based.
Each input is generated as A=L*transpose(L), with integral lower
triangular factors, diagonal entries in [2,4], and off-diagonal
entries in [-2,2]. Matrix storage is column-major. Both computed
factors are checked against the generated factor for every run.
Average speedup is the arithmetic mean of per-input scalar_cycles /
vector_cycles. The ratio of mean cycles is also reported. Instruction
speedup is calculated the same way using retired instruction counts.
Build preset: test (C++20, Qt 6.9.3, MinGW GCC 13.1.0).
Observed benchmark runtime: 15.5 seconds.
Memory bases: A=0x2000, L=0x3000.
Set KITES_RVSS_CHOLESKY_SAMPLES before running the test to change
the sample count; the default used here is 3.
Inputs and measured counters are included in the CSV below.

Interpretation highlights
-------------------------
At N=8, the average cycle speedup is 1.5439x. Values above 1.0 mean the vector implementation used fewer
cycles; values below 1.0 mean it was slower. The complete table
shows how the speedup changes as matrix dimension increases.

Notes and interpretation
------------------------
Speedup above 1.0 means the vector implementation used fewer cycles
(or instructions) than its scalar counterpart; below 1.0 means it
was slower. Per-input speedups are averaged so that each generated
matrix has equal weight. Cycle counts include instruction execution
and memory activity in this simulator. Results are specific to the
RVSS simulator, these kernels, and the tested dimensions; they are
not hardware timing claims. Regenerate with:

    cmake --build --preset test --target kites_vector_test
    ctest --preset test -R RVSSCholeskyScaling
